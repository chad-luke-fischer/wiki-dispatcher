# Garden index

The garden is the pattern wiki that evolves the skill library. Open this folder as an Obsidian
vault. Layout mirrors WikiSkill (arXiv 2608.27454): `raw/traces/` are immutable execution
traces, `wiki/patterns/` are root-caused lessons, `skill-impact.md` is the acceptance ledger,
`logs.md` is the append-only journal, `pending/` holds proposals awaiting a human.

Index rows are written by the Wiki Maintainer in the form
`[[patterns/name|name]]: PROBLEM — ROOT CAUSE — fix: FIX` so the Skill Proposer can scan them
without opening pages.
